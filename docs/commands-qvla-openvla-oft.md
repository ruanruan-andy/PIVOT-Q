# qvla-openvla-oft: Train / Eval

After [workspace configuration](../env/README.md#configure-a-new-workspace),
set the workspace root and load local paths in each experiment terminal:

```bash
export PIVOT_Q_ROOT=/path/to/PIVOT-Q
export PIVOT_Q_DIR="$PIVOT_Q_ROOT"
source "$PIVOT_Q_DIR/env/runtime/paths.sh"
```


Follow [Setup](../env/qvla-openvla-oft.md) before running these commands.

## Execution

Change `--seed` for another evaluation repetition; add `--resume` to continue.

Run one suite per terminal for parallel evaluation. For serial evaluation, select the same GPU and run commands sequentially.


Use one service pair per suite. Start the following eight services in separate
windows; wait for `Ready`. Reuse a pair sequentially across methods, never for
concurrent model clients.

```bash
cd "$PIVOT_Q_DIR/openvla-oft-qvla"
conda activate libero_test
```

```bash

```

Use gates generated by the current calibration pipeline: balanced clean-rollout
sampling, marginal-cost allocation, and no 0-bit pruning by default. Legacy
gates are rejected. Regenerate calibration, proxies, and gates together before
retraining PIVOT-Q or Full Distill; do not resume adapters from old gates.
The 4-bit target is averaged over output channels, not weight parameters.

If matching calibration files/gates were not copied, run `collect-calibration`
then `prepare-qvla` for each suite using the same suite/port flags below before
quantized eval or training. Complete copied packs do not need rebuilding.
